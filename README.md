# ⚙ Installation

Clone repository

```bash
git clone https://github.com/alimaqsoodahmed/alimaqsoodahmed-portfolio.git
```

Open folder

```bash
cd alimaqsoodahmed-portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
